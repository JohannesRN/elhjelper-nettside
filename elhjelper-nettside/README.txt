ELHjelper nettside – første versjon

Mappestruktur:

elhjelper-nettside/
├── index.html
├── style.css
├── script.js
└── assets/
    └── logo.png

Køyr lokalt:

1. Opne mappa i VS Code.
2. Installer eventuelt Live Server-utvidinga.
3. Høgreklikk på index.html → Open with Live Server.

Nettsida er laga utan rammeverk og kan seinare leggast på Cloudflare Pages.
